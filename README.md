# 📸 InstaLoader Pro - Web Downloader

A lightweight web application built with **Flask** and **Python** that allows users to download Instagram Reels as **MP4 video** or convert them to **MP3 audio**.

## 🚀 Features
* **Video Download:** Fetches high-quality MP4s directly from Instagram.
* **Audio Extraction:** Automatically converts Reels to MP3 using `moviepy`.
* **Smart Metadata:** auto-detects captions to name files correctly.
* **Web Interface:** Clean, responsive UI with a progress bar.

## 🛠️ Installation

1.  **Clone the repository**
    ```bash
    git clone https://github.com/NOORBAJI55/Instagram_Reel_Downloader
    cd Instagram_Reel_Downloader
    ```

2.  **Install Dependencies**
    ```bash
    pip install -r requirements.txt
    ```

3.  **Run the App**
    ```bash
    python app.py
    ```

4.  **Open in Browser**
    Visit `http://127.0.0.1:5000`
